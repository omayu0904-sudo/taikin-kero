# 退勤ケロ 🐸

時計のそばに座るカエルが、出勤・退勤までの残り時間を吹き出しで教えてくれるデスクトップ常駐アプリ(Electron製)。

## 動かし方

1. [Node.js](https://nodejs.org/) をインストール
2. このフォルダで:

```
npm install
npm start
```

初回は設定ウィンドウが開くので、出勤・退勤時間と出勤する曜日を決めてください。

## 配布用ファイルを作る

```
npm run dist:win   # Windows(portable exe) ※Windowsで実行
npm run dist:mac   # Mac(zip) ※Macで実行
```

`dist/` フォルダに出力されます。署名していないため、受け取った人は最初に警告が出ることがあります(Windowsは「詳細情報→実行」、Macは「システム設定→プライバシーとセキュリティ→このまま開く」)。

## カエルの動き

| 状態 | 動き | 音 |
| --- | --- | --- |
| 出勤前 | 寝ている「出勤まで○分」 | - |
| 出勤時間 | 起きる | ケロ(上昇) |
| 勤務中 | ゆらゆら「退勤まで○分」 | 30分ごとにケロ |
| 退勤時間(5分間) | 紙吹雪とジャンプ | ファンファーレ |
| 退勤5分後〜 | 光って震える「まだいるの？！」 | 下降音 |
| 出勤しない曜日 | 寝ている「おやすみの日」 | - |

## 操作

- クリック: ジャンプ / ドラッグ: 移動 / 右クリック: メニュー(設定・音・位置固定・自動起動・プレビュー・終了)
- Macはメニューバーに小さな緑のアイコンが出ます(右クリックでもメニューが開けます)。

## カスタマイズ

- カエルの絵は `index.html` 内のSVGです。自分の絵に差し替える場合は `<svg id="frog">` を `<img>` などに置き換えてください。
- セリフは `index.html` の `compute()` 内の文字列を編集してください。
- 音は WebAudio で合成しているので、音声ファイルは不要です(`SND` を編集)。
